## Phase Goal

ROADMAP goal (verbatim): "The owner has a clean, approved history published to `origin` and a written workflow for how cleanup work lands afterward."

<objective>
Stage 1 of the D-05 publish. Get the owner's Gate 2 approval for the proven tip, push it to the throwaway branch `curated-main` (never `main`), and have the owner open a pull request so CI runs on GitHub without touching the deploy path. Record each CI job's result for Gate 3.

Purpose: GIT-02 says history reaches `origin/main` only after the owner approves. D-05 asks to see CI on GitHub before `main` moves. A branch push alone triggers nothing, because `ci.yml` runs only on `pull_request` and on pushes to `main`, so a PR is required (RESEARCH Pitfall 6).
Output: `origin/curated-main` at the curated tip, an open PR, and `## Staging CI results` in the proposal.

No tracer task: this plan is a gated publish step. Its first task has to be the decision checkpoint, because the push is a one-way door.
</objective>
