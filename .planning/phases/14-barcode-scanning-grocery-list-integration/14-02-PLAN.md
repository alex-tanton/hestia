<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser Runtime -> Camera Hardware | Camera stream access requested via navigator.mediaDevices.getUserMedia |
| Video Stream -> Frame Analyzer | Continuous video frames decoded by BarcodeDetector API |
| Client Storage -> User Preferences | Persistent mode selection stored in browser localStorage |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-14-04 | Denial of Service | Video frame detection loop | high | mitigate | Throttle frame processing to 150ms-200ms interval (avoiding 60fps continuous CPU saturation) and enforce strict 1.8-second debounce window on identical barcodes to prevent duplicate scan writes. |
| T-14-05 | Information Disclosure / Resource Leak | Camera MediaStream | high | mitigate | Implement strict useEffect cleanup that iterates stream.getTracks() and calls track.stop() on every active track when the scanner dialog closes or unmounts, extinguishing hardware indicator LED. |
| T-14-SC | Tampering | npm dependencies (@undecaf/barcode-detector-polyfill) | high | mitigate | Polyfill package verified via Package Legitimacy Audit in RESEARCH.md with [OK] verdict; dynamic import ensures WASM and polyfill code are only evaluated on browsers lacking native BarcodeDetector. |
</threat_model>
