## Phase Goal

ROADMAP goal (verbatim): "Enable passwordless magic link authentication end-to-end with verified email delivery."

This plan establishes the foundation: GoTrue SMTP configuration for Resend (`smtp.resend.com:465`) under sender `auth@aberrance.app`, signup lockdown (`GOTRUE_DISABLE_SIGNUP: 'true'`), 15-minute OTP expiry (`GOTRUE_MAILER_OTP_EXP: 900`), the static email template delivering both confirmation link and 6-digit OTP code via Caddy (`http://caddy:8080/templates/magic_link.html`), and the `inbucket` test-double container in the E2E Compose topology with dynamic loopback port allocation.

<threat_model>
### Security Threat Model (ASVS L1)
- **T-10-01** (ASVS 2.1.1 / AUTH-03): Unauthenticated public visitor account creation via magic link signup probe.
  - Threat: Arbitrary users submit uninvited email addresses to trigger account creation and pollute tenant database with orphaned auth users.
  - Mitigation: Set `GOTRUE_DISABLE_SIGNUP: 'true'` in `docker/docker-compose.yml`, preventing public self-registration while preserving admin provisioning via `service_role`.
  - Test: `apps/service/src/docker-compose-smtp.test.ts` validates `GOTRUE_DISABLE_SIGNUP: 'true'` in Compose.
- **T-10-02** (ASVS 5.1.4 / AUTH-04): Open redirect attack via manipulated `redirect_to` parameter in magic link verification.
  - Threat: Phishing attacker crafts magic link with malicious redirect URI parameter to harvest auth tokens.
  - Mitigation: Lock `GOTRUE_SITE_URL: ${HESTIA_ORIGIN}` and `GOTRUE_URI_ALLOW_LIST: ${HESTIA_ORIGIN},${HESTIA_ORIGIN}/**`.
  - Test: `apps/service/src/docker-compose-smtp.test.ts` asserts strict origin locking in `docker-compose.yml`.
- **T-10-03** (ASVS 2.3.1 / AUTH-03): Prolonged OTP exposure window leading to brute force or replay attacks.
  - Threat: Attackers intercept or guess 6-digit OTP codes if the validity window is excessively long (default 1 hour).
  - Mitigation: Tighten `GOTRUE_MAILER_OTP_EXP: 900` (15 minutes) in Compose and `supabase/config.toml`.
  - Test: `apps/service/src/docker-compose-smtp.test.ts` asserts `GOTRUE_MAILER_OTP_EXP: 900`.
</threat_model>
