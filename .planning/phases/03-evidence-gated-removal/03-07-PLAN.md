<ledger_check>
The ledger check compares base and tip summaries against the ledger. A summary line's key is `{path}:{symbol}`; for a `files` line (symbol `-`) it is `{path}`; for a `duplicates` line it is `{path}:` followed by the first name before `|`. A ledger section's keys are the backticked first value in its Item column: column 2 of `## Removals`, column 1 of `## Kept (for the owner list)` and of an optional `## Drift from other merges` table (Item, Cause). The drift table records lines that changed because of a merge outside Phase 3, for example Dependabot PR #9, with the commit that caused each. The check fails when a line left the summaries but its key is not in Removals or Drift, when a line joined them but its key is not in Kept or Drift, or when a Removals key is still reported. Run it as:

`node -e 'const fs=require("fs");const a=process.argv.slice(1);const t=fs.readFileSync(a[0],"utf8");const sec=(h)=>{const i=t.indexOf("\n## "+h);if(i===-1)return "";const j=t.indexOf("\n## ",i+4);return j===-1?t.slice(i):t.slice(i,j)};const col=(s,n)=>new Set(s.split("\n").filter(r=>r.startsWith("|")).map(r=>(r.split("|")[n]||"").match(/`([^`]+)`/)).filter(Boolean).map(m=>m[1]));const rem=col(sec("Removals"),2),kept=col(sec("Kept"),1),drift=col(sec("Drift"),1);const key=(l)=>{const f=l.split("\t");return f[2]==="-"?f[1]:f[1]+":"+f[2].split("|")[0]};const rd=(f)=>new Set(fs.readFileSync(f,"utf8").split("\n").filter(l=>l&&!l.startsWith("total\t")));let bad=0;for(let i=1;a.length>i;i+=2){const b=rd(a[i]),z=rd(a[i+1]);for(const l of b){if(!z.has(l)&&!rem.has(key(l))&&!drift.has(key(l))){console.log("removed, not in Removals: "+l);bad=1}}for(const l of z){if(!b.has(l)&&!kept.has(key(l))&&!drift.has(key(l))){console.log("added, not in Kept: "+l);bad=1}if(rem.has(key(l))){console.log("in Removals, still reported: "+l);bad=1}}}process.exit(bad)' "$LED" {base-summary} {tip-summary} [{base-summary} {tip-summary} ...]`
