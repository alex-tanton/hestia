# Spike Conventions: Material Design 3 Redesign

Established patterns and stack choices from the Pure MD3 spike session.

## Stack
- **Frontend Framework:** React 19 + TypeScript + Vite 8
- **Styling Architecture:** Pure Material Design 3 CSS using tokens generated by `@material/material-color-utilities` (seed `#B4532A` Warm Terracotta).
- **CSS Dependencies:** Zero utility-class frameworks. Tailwind CSS is eliminated in favor of semantic MD3 CSS variables and native CSS Grid/Flexbox layouts.
- **Components:** Custom lightweight MD3 elements and official `@material/web` components where appropriate.

## Surface Container Hierarchy
- Canvas: `var(--md-sys-color-surface)`
- Scrolled Top App Bar & Navigation: `var(--md-sys-color-surface-container)`
- Cards / Panels: `var(--md-sys-color-surface-container-low)`
- Nested Items inside Cards: `var(--md-sys-color-surface-container-lowest)`
- Dialogs, Popovers & Menus: `var(--md-sys-color-surface-container-high)`
- Chips & Input Fields: `var(--md-sys-color-surface-container-highest)`

## Elevation & Shapes
- Elevation: Level 0 (flat/outlined), Level 1 (standard cards), Level 2 (hover/scrolled bar), Level 3 (FAB/dialogs)
- Border Radii: 8px (small elements/chips), 12px (swatches/menus), 16px (cards & FABs), 9999px (pill indicators, buttons, badges)

## Navigation Conventions
- **Desktop (>=600px):** 88px Navigation Rail on leading edge + Top App Bar (64px)
- **Mobile (<600px):** Top App Bar (56px) + Bottom Navigation Bar (80px) with 64x32px active pill indicators (`secondary-container`)
