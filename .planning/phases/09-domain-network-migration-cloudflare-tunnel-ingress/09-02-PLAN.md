## Phase Goal

ROADMAP goal (verbatim): "Establish secure ingress for `hestia.aberrance.app` via Cloudflare Tunnel, eliminating Tailscale Funnel and port forwarding."

09-01 removed the published host port and added the tunnel connector. This plan moves the two production paths that depended on the old shape: the deploy script's health gate, which probed a host port, and Caddy's entrypoint, which must now also guard the new trust list. It also stops CI from pulling an image E2E never runs.

<objective>
Move `scripts/deploy.sh`'s health check into the caddy container and start `cloudflared` with the supporting services; keep the tunnel image out of CI's pre-pull; make `docker/caddy-entrypoint.sh` refuse an empty trust list and name the new origin; and prove the entrypoint with a harness test and a probe of the real Caddy image.

Purpose: without Task 1, every deploy after this phase would fail its health gate and roll back (research Pitfall 1). Without Task 2, a missing trust list would silently merge every visitor into one rate-limit bucket (Pitfall 5).

Output: two commits, one new harness test, the root `test:harness` list extended by one file.
</objective>
