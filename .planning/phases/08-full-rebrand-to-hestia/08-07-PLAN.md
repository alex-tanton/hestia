This plan locks the rebrand in (D-13: a "no old name left" guard in the existing hygiene gate, with an explicit allowlist) and delivers success criterion 6 ("All existing unit, component, integration, and E2E tests pass cleanly under the new brand") with a full local run of every CI check, the integration suite and the E2E suite.

Purpose: D-13 makes any future regression to the old name a blocking CI failure; BRAND-06 requires every suite green under the new brand.

Output: a `ci:` guard commit and a `docs:` commit, plus a verification record (no code change) for the full suite and integration (Task 2) and for E2E (Task 3).
