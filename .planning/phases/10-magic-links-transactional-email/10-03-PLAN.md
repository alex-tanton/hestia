## Phase Goal

ROADMAP goal (verbatim): "Enable passwordless magic link authentication end-to-end with verified email delivery."

This plan delivers the end-to-end integration and operations layer: the Inbucket REST client helper in `e2e/support/inbucket.ts`, the comprehensive Playwright E2E suite `e2e/tests/07-magic-link.spec.ts` replacing `07-magic-link-disabled.spec.ts`, and canonical runbook documentation in `docs/deployment.md` detailing Cloudflare DNS records (SPF, DKIM, DMARC, return-path) and the GoTrue recreation step.

<threat_model>
### Security Threat Model (ASVS L1)
- **T-10-06** (ASVS 2.2.1 / AUTH-05): Credential harvesting or session hijacking via invalid or expired OTP code replay.
  - Threat: Attacker replays expired or guessed 6-digit OTP code to gain unauthorized session access.
  - Mitigation: GoTrue invalidates OTP code immediately upon first use or expiration; invalid codes return HTTP 400 and fail session creation.
  - Test: Playwright test in `e2e/tests/07-magic-link.spec.ts` asserting code `000000` is rejected with `That code is incorrect or has expired. Ask for a new one.`
- **T-10-07** (ASVS 3.8.1 / AUTH-04 & AUTH-05): End-to-end open redirect token leakage.
  - Threat: Attackers craft external redirect URLs to steal tokens via referrer or redirect chains.
  - Mitigation: Verify at runtime that GoTrue rejects external redirects outside `${HESTIA_ORIGIN}`.
  - Test: Playwright test in `e2e/tests/07-magic-link.spec.ts` testing open redirect rejection.
- **T-10-08** (ASVS 2.1.3 / AUTH-05): Unsolicited email dispatch to unverified/uninvited email addresses.
  - Threat: Spammers use magic link endpoint as an open relay to send emails to arbitrary third parties.
  - Mitigation: GoTrue rejects OTP generation for unknown emails when signup is disabled, producing zero outbound emails.
  - Test: Playwright test in `e2e/tests/07-magic-link.spec.ts` asserting Inbucket mailbox for uninvited email remains completely empty.
</threat_model>

   ```typescript
   import { INBUCKET_BASE_URL } from './env.ts';

   export interface InbucketMessageHeader {
     mailbox: string;
     id: string;
     from: string;
     to: string[];
     subject: string;
     date: string;
     size: number;
   }

   export interface InbucketMessageDetail extends InbucketMessageHeader {
     body: {
       text: string;
       html: string;
     };
     header: Record<string, string[]>;
   }

   export async function purgeMailbox(usernameOrEmail: string): Promise<void> {
     const mailbox = usernameOrEmail.split('@')[0];
     await fetch(`${INBUCKET_BASE_URL}/api/v1/mailbox/${mailbox}`, { method: 'DELETE' });
   }

   export async function waitForLatestEmail(
     usernameOrEmail: string,
     timeoutMs = 10000,
   ): Promise<InbucketMessageDetail> {
     const mailbox = usernameOrEmail.split('@')[0];
     const start = Date.now();
     while (Date.now() - start < timeoutMs) {
       const res = await fetch(`${INBUCKET_BASE_URL}/api/v1/mailbox/${mailbox}`);
       if (res.ok) {
         const messages = (await res.json()) as InbucketMessageHeader[];
         if (messages.length > 0) {
           const latest = messages[messages.length - 1];
           const detailRes = await fetch(`${INBUCKET_BASE_URL}/api/v1/mailbox/${mailbox}/${latest.id}`);
           if (detailRes.ok) {
             return (await detailRes.json()) as InbucketMessageDetail;
           }
         }
       }
       await new Promise((resolve) => setTimeout(resolve, 200));
     }
     throw new Error(`Timed out waiting for email to ${usernameOrEmail} in Inbucket`);
   }

   export function extractOtpCode(email: InbucketMessageDetail): string {
     const match = email.body.html.match(/\b\d{6}\b/) ?? email.body.text.match(/\b\d{6}\b/);
     if (!match) throw new Error(`Could not find 6-digit OTP code in email body: ${email.body.html}`);
     return match[0];
   }

   export function extractConfirmationUrl(email: InbucketMessageDetail): string {
     const match = email.body.html.match(/href="([^"]*\/auth\/v1\/verify[^"]*)"/);
     if (!match) throw new Error(`Could not find confirmation URL in email body: ${email.body.html}`);
     return match[1].replace(/&amp;/g, '&');
   }
   ```
