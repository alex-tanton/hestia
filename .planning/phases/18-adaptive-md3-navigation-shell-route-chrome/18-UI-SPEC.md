## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gaps, badge padding, indicator radius offsets |
| sm | 8px | Compact element spacing, navigation destination vertical padding, chip internal gap |
| md | 16px | Default element spacing, Top App Bar horizontal padding, screen margin gutter |
| lg | 24px | Section padding, modal bottom sheet horizontal padding, navigation rail top margin |
| xl | 32px | Layout gaps, indicator pill width margin, bottom sheet handle offset |
| 2xl | 48px | Major section breaks, NavigationRail destination vertical cadence |
| 3xl | 64px | Page-level spacing, Small Top App Bar container height (64px) |

Exceptions:
- `80px` (5rem): Standard MD3 NavigationBar container height (`min-h-[80px]`) and NavigationRail container width (`w-[80px]`) per Material Design 3 window size class navigation guidelines.
- `56px` (3.5rem): Navigation active indicator pill capsule width (`56px × 32px`) per MD3 navigation specs.
- `44px` / `48px`: Minimum accessible touch target geometry for icon buttons (`<md-icon-button>` 48px target) and navigation destination tap areas.

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px | 400 | 1.5 |
| Label | 12px | 600 | 1.5 |
| Heading | 20px | 600 | 1.2 |
| Display | 28px | 600 | 1.2 |

Typography rules:
- Exactly 4 font sizes declared: 12px (Label / Caption / Navigation destination text), 14px (Body text / descriptions / list rows), 20px (Heading / Top App Bar single `<h1>` / section `<h2>`), 28px (Display / Hero titles).
- Exactly 2 font weights declared: 400 (Regular — body copy, descriptions, inactive navigation labels), 600 (Semi-bold/Medium — headings, Top App Bar title, active navigation labels, button labels, tab titles).
- Line heights: Body roles use 1.5 (21px for 14px body, 18px for 12px label); Heading and Display roles use 1.2 (24px for 20px heading, 34px for 28px display).

## UI Considerations

Applicable state considerations resolved: 7 covered, 0 backstop, 0 unresolved

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| zero-one-many | HouseholdSwitcher trigger & sheet | ✅ covered | When `households.length === 1`, switcher trigger button remains clickable with `${name}, switch household` accessible label; sheet opens indicating active household with checkmark, displaying the documented "No other households" copy and "Join or create household" action. When `households.length > 1`, clicking any other household triggers selection, switches active household, and closes sheet. |
| empty | RecipeLibraryScreen "On sale / Ready now" filter | ✅ covered | When the "On sale / Ready now" filter chip is engaged and zero recipes match pantry or deal criteria, renders a `surfaceContainerLow` card with the documented "No matching recipes" heading, body, and "Clear recipe filter" CTA. |
| loading | HouseholdSwitcher Top App Bar trigger | ✅ covered | While `households === undefined`, renders a tonal skeleton pill (`surfaceContainerHighest`, 112px × 20px, `role="status"`, screen-reader text "Loading households") to prevent header layout shift. |
| overflow | Top App Bar title and household name | ✅ covered | Long household names in the switcher trigger and long screen titles truncate cleanly with CSS ellipsis (`truncate`), ensuring the back navigation button and settings button remain fully visible, accessible, and unclipped. |
| overflow | SubTabs horizontal tab bar | ✅ covered | On narrow viewports (`<375px`), `MdTabs` renders inside a horizontal touch-scrollable navigation container (`overflow-x-auto` without visible scrollbars) preventing label clipping or text wrapping across 4-tab pillars (Lists). |
| scroll-transition | Small Top App Bar (64px) | ✅ covered | At `scrollY = 0`, Top App Bar displays flat `surface` background with zero elevation level; on scroll (`scrollY > 4px`), smoothly tints to `surfaceContainer` (elevation level 2) via CSS transition on `background-color`, eliminating 1px border dividers. |
| responsive-breakpoint | Adaptive Navigation Shell (600px Window Size Class) | ✅ covered | Viewports `<600px` render bottom 5-destination `NavigationBar` (80dp height, `min-h-[80px]`, `surfaceContainer` fill, safe area padding) with Settings button in Top App Bar; viewports `>=600px` render left 80dp `NavigationRail` with top 5 destinations, inset divider, and bottom-pinned Settings destination, while Top App Bar omits Settings button. |
