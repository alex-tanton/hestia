# Spike Sources

The spike source files, HTML prototypes, and CSS stylesheets developed during the Pure MD3 redesign are stored in `.planning/spikes/`:

- `001-pure-md3-styling-foundation/`: Pure MD3 tokens and base styling prototype.
- `002-md3-shell-and-navigation/`: Navigation rail and bottom bar with active pill indicators.
- `003a-md3-cards-elevated-tonal/`: Elevated / filled card treatment with tonal depth.
- `003b-md3-cards-outlined/`: Outlined card treatment with 1px border.
- `004-md3-screens-visual-showcase/`: Multi-screen showcase (Dashboard, Shopping, Bills, Meals).
- `005-authentic-official-md3/`: Official Google Blue and Iris M3 color schemes and 8dp spacing.
- `006-theme-1-light-dark-showcase/`: Complete Theme 1 (Google Blue) Light and soft pastel Dark mode showcase with name-only household switcher.
