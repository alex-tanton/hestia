    1. In apps/web/src/screens/lists/ListDetailScreen.tsx:
       - Imports:
         - ScanBarcode icon from lucide-react.
         - BarcodeScannerDialog from ../../components/lists/BarcodeScannerDialog.tsx.
         - fetchBarcodeProduct from ../../lib/api/barcode-hooks.ts.
         - matchScannedItem from ../../lib/barcode/matching.ts.
         - useApi from ../../lib/api/api-context.tsx.
       - State:
         - isScanning: boolean, default false.
         - scannerDraft: Partial<ItemDraft> | undefined.
       - Toolbar Button (per D-01):
         - In list header toolbar (!isArchived && detail !== undefined):
           Place a secondary button directly beside "Add an item":
           <Button variant="secondary" onClick={() => setIsScanning(true)}>
             <ScanBarcode className="mr-1.5" size={18} />
             Scan barcode
           </Button>
       - Scan Handler: handleScan(barcode: string, mode: 'add' | 'shop'):
         - Mode 'add' (SCAN-03):
           - Call fetchBarcodeProduct(api, barcode) within try/catch.
           - On resolution:
             - Format item name: if brands and productName exist, `${brands} ${productName}`; else productName || barcode.
             - Close scanner dialog: setIsScanning(false).
             - Set scannerDraft: { itemName: formattedName, barcode, quantity: 1 }.
             - Set isAdding(true) to open ItemSheet pre-populated with scannerDraft.
           - On lookup miss / network error:
             - Close scanner dialog: setIsScanning(false).
             - Set scannerDraft: { itemName: '', barcode, quantity: 1 }.
             - Set isAdding(true).
             - Display toast: { variant: 'info', message: 'Barcode not found. Enter item details manually.' }.
         - Mode 'shop' (SCAN-04, D-04):
           - Filter unbought items: const unbought = (detail?.items ?? []).filter(item => item.status !== 'bought').
           - Check offline exact match: const exact = unbought.find(item => item.barcode === barcode).
           - If exact match found:
             - Call executeCheckOff(exact, barcode).
           - If no direct barcode match:
             - Look up product name via fetchBarcodeProduct(api, barcode).catch(() => null).
             - Call matchScannedItem(unbought, barcode, product?.productName ?? null).
             - If matchResult.exactBarcodeMatch:
               - Call executeCheckOff(matchResult.exactBarcodeMatch, barcode).
             - Else if matchResult.normalizedNameMatch:
               - Call executeCheckOff(matchResult.normalizedNameMatch, barcode).
             - Else if matchResult.candidateMatches.length > 1:
               - Display toast informing user of ambiguous matches or prompt for selection.
             - Else:
               - Display toast: { variant: 'info', message: `${product?.productName ?? 'Item'} is not on this list.` }.
               - Keep scanner active for subsequent scans per D-04.
         - Helper executeCheckOff(item: ListItem, scannedBarcode: string):
           - Mutate item status via updateItem.mutate:
             kind: 'update-item',
             householdId,
             listId,
             itemId: item.id,
             itemName: item.itemName,
             patch: { status: 'bought', ...(!item.barcode ? { barcode: scannedBarcode } : {}) }
           - Display interactive floating toast with Undo per D-04:
             toast({
               variant: 'success',
               message: `${item.itemName} marked bought`,
               action: {
                 label: 'Undo',
                 onAction: () => {
                   updateItem.mutate({
                     kind: 'update-item',
                     householdId,
                     listId,
                     itemId: item.id,
                     itemName: item.itemName,
                     patch: { status: 'needed' },
                   });
                 },
               },
             })
           - Scanner dialog remains open (isScanning stays true) so user can continue scanning additional items without reopening camera per D-04.
       - In ItemSheet invocation: pass initialDraft={scannerDraft}. When onOpenChange(false) fires, clear scannerDraft(undefined).
       - Render BarcodeScannerDialog:
         <BarcodeScannerDialog
           open={isScanning}
           onOpenChange={setIsScanning}
           onScan={handleScan}
         />
