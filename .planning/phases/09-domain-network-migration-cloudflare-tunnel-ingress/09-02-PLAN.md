## Phase Goal

ROADMAP goal (verbatim): "Establish secure ingress for `hestia.aberrance.app` via Cloudflare Tunnel, eliminating Tailscale Funnel and port forwarding."

09-01 removed the published host port, removed the network's pinned gateway and added the tunnel connector. This plan moves the production paths that depended on the old shape. The deploy script must survive the one-time network recreate, and its health gate probed a host port. Caddy's entrypoint must now also guard the new trust list. The plan also stops CI from pulling an image E2E never runs.

<objective>
Make `scripts/deploy.sh` prepare the whole project before its subset start, so the first deploy's network recreate completes. Move its health check into the caddy container, and start `cloudflared` with the supporting services. Keep the tunnel image out of CI's pre-pull. Make `docker/caddy-entrypoint.sh` refuse an empty trust list and name the new origin. Prove the deploy sequence on a disposable Compose stack, and prove the entrypoint with a harness test and a probe of the real Caddy image.

Purpose: without Task 1, the first deploy of this phase would stop the data services and fail half-way through recreating the network (measured below). Every later deploy would fail its health gate and roll back (research Pitfall 1). Without Task 2, a missing trust list would silently merge every visitor into one rate-limit bucket (Pitfall 5).

Output: two commits, one new harness test, the root `test:harness` list extended by one file.
</objective>
