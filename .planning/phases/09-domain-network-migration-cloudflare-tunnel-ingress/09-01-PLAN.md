## Phase Goal

ROADMAP goal (verbatim): "Establish secure ingress for `hestia.aberrance.app` via Cloudflare Tunnel, eliminating Tailscale Funnel and port forwarding."

This plan builds the ingress itself: Caddy's client-address rule, the tunnel connector in Compose, the stack with no published port, the E2E overlay that keeps working without Cloudflare, and the new origin in `.env.example`. Later plans move the deploy script and the Caddy entrypoint onto it (09-02), sweep test fixtures to the new origin (09-03), rewrite the docs and the owner checklist (09-04) and lock the result in with the hygiene guard and a full CI and E2E run (09-05).

<objective>
Make Caddy take the client address from `CF-Connecting-IP` only, trusted only from the Compose subnet (the cloudflared hop), with no published host port; add the `cloudflared` service with a required token; keep E2E working without Cloudflare; put `https://hestia.aberrance.app` and the token in `.env.example` and `generate-secrets.sh`; and pin it all with E2E spec 20 and a static Vitest test.

Purpose: NET-02 and NET-03 are the heart of the phase, and D-04 to D-06 decide how the real client address survives the tunnel. Proving that path on the real stack first (Task 1) catches a wrong trust rule before anything else builds on it.

Output: three commits (tracer, connector and env, static test), one new E2E spec, one renamed E2E spec, one new Vitest file.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| internet → Cloudflare edge → cloudflared → Caddy | public traffic arrives only through the tunnel; request headers are client-controlled until the edge sets `CF-Connecting-IP` |
| Compose network → Caddy | any peer on the `hestia` bridge can reach `caddy:8080`; only this subnet is trusted to name the client |
| host `.env` → containers | the tunnel token and every secret cross from the 0600 env file into container environments |
| sandbox → Docker builds | the E2E image builds need the proxy's CA bundle, which must never reach a commit or a runtime image |
