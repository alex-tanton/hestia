## Visual Hierarchy & Anchors

- **Primary Visual Anchor:** 64x64px (`size-16`) product thumbnail container (`DealImage`) in `DealCard`, paired with the bold deal title (`text-h3 text-primary`).
- **Secondary Visual Anchor:** Prominent green unit price headline (`text-h3 tabular-nums text-section`) and percentage discount pill (`Badge variant="section"`).
- **Tertiary Elements:** Merchant store name (`text-body-sm text-secondary`) and flyer validity date range (`text-caption text-muted`).
- **Action Affordance:** "Add Deal to List" button (`Button variant="outline"`).
- **Accessibility Fallback:** `ImageOff` icon is marked `aria-hidden="true"`; visual placeholder container carries `data-testid="deal-image-placeholder"`; image itself uses decorative `alt=""` because the adjacent item title (`deal.name`) provides the accessible label without duplicate screen-reader announcements.

## UI Considerations

> Populated by the ui-phase UI-consideration probe (Step 9.5) and lifted by plan-phase's
> `## UI Considerations` lift rule via the identical rule as SPEC `## Edge Coverage`. Shape-rooted UI *state*
> coverage (empty / loading / error / populated / partial / overflow / zero-one-many / long-text).
> Empty-state and error-state COPY live in `## Copywriting Contract` above — this section covers
> state coverage and REFERENCES those rows rather than restating the copy (de-dup).

Applicable state considerations resolved: 7 covered, 1 backstop, 0 unresolved

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| empty | DealImage (`media`) | ✅ covered | When URL is null or disallowed by domain policy, renders `bg-raised` container with `ImageOff` icon, preserving card layout box without shifts |
| loading | DealImage (`media`) | ✅ covered | Uses native `loading="lazy"` and `decoding="async"`; container `bg-raised` holds layout space until image bytes stream in |
| error | DealImage (`media`) | ✅ covered | When image network load fails (`onError`), flips `hasFailed` state to render placeholder container with `ImageOff` icon |
| populated | DealImage (`media`) | ✅ covered | Allowed HTTPS CDN image renders with `object-contain`, `rounded-sm`, and decorative `alt=""` |
| overflow | DealImage (`media`) | ✅ covered | Container enforces `shrink-0 overflow-hidden rounded-sm` and `size-16` / `size-12` / `size-8` dimensions, preventing oversize bitmaps from overflowing |
| zero-one-many | Deal list (`list-collection`) | ✅ covered | 0 deals renders empty state (see Copywriting Contract); 1 to many deals render in 1-column or 2-column responsive grid |
| long-text | Deal name (`static-content`) | ✅ covered | Long product names truncate or wrap cleanly with `min-w-0 flex-1` flex child rules without clipping image |
| error | Deal list network error (`list-collection`) | 🧪 backstop | When flyer/deal fetch fails offline or on network error, renders ErrorState with documented error copy and retry action |
