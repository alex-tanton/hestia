## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gaps, chip checkmark gap, badge padding |
| sm | 8px | Compact element gaps, button icon spacing, chip strip horizontal gap |
| md | 16px | Default element spacing, card padding, dialog padding, list row horizontal padding |
| lg | 24px | Section padding, modal bottom sheet horizontal padding, form card padding |
| xl | 32px | Layout gaps, grid spacing between planner board columns, settings group spacing |
| 2xl | 48px | Major section breaks, FAB clearance margin, empty state illustration offset |
| 3xl | 64px | Page-level spacing, Top App Bar container height (64px) |

Exceptions:
- `48px`: Accessible touch target minimum for icon buttons (`<md-icon-button>`), list row checkboxes, quick action icons, and delete buttons.
- `56px`: Standard MD3 text field container height (`<md-outlined-text-field>`).
- `80px`: Shell navigation container dimension (`min-h-[80px]` NavigationBar / `w-[80px]` NavigationRail).

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Label | 12px | 600 | 1.5 |
| Body | 14px | 400 | 1.5 |
| Heading | 20px | 600 | 1.2 |
| Display | 28px | 600 | 1.2 |

Typography rules:
- Exactly 4 font sizes declared: 12px (Label / Caption / status badge text / helper text), 14px (Body text / descriptions / list rows / input values), 20px (Heading / Top App Bar single `<h1>` / card section `<h2>` / dialog title), 28px (Display / Hero spend title).
- Exactly 2 font weights declared: 400 (Regular — body copy, descriptions, input text, inactive chip labels), 600 (Semi-bold/Medium — headings, display titles, button labels, active chip labels, card headers).
- Line heights: Body roles use 1.5 (21px for 14px body, 18px for 12px label); Heading and Display roles use 1.2 (24px for 20px heading, 34px for 28px display).

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FFF8F6` (light) / `#1A110E` (dark) | MD3 Surface canvas background, page main canvas (`bg-surface`), full-screen dialog canvas |
| Secondary (30%) | `#FCEAE4` (light) / `#271E1A` (dark) | MD3 Surface Container (`surfaceContainer` / `surfaceContainerLow` `#FFF1EC` / `#231A16`): Planner board columns, Subscriptions Hero card, Readiness card, ModalBottomSheet surface, dialog interiors, settings section cards |
| Accent (10%) | `#8E4C32` (light) / `#FFB599` (dark) | MD3 Primary (paired with `secondaryContainer` `#FFDBCE` / `#5D4035`): active indicators, selected chips, focus rings, primary action buttons |
| Destructive | `#BA1A1A` (light) / `#FFB4AB` (dark) | MD3 Error (paired with `errorContainer` `#FFDAD6` / `#93000A`): destructive confirmation dialogs, overdue alert rows, expired items, departure delete actions |

Accent reserved strictly for:
1. Primary CTA button container backgrounds (`<md-filled-button>` / `<Button variant="primary">`)
2. Floating Action Buttons (`<md-fab>`) for creating meals, bills, chores, and errands
3. Selected filter chips container (`<md-filter-chip selected>`) and active Segmented Button slot (`Breakfast | Lunch | Dinner`)
4. Focus ring highlight outline (`--md-focus-ring-color`)
5. Active toggle switch fill (`<md-switch selected>`)
6. Checkbox checked fill on active errand items (`<md-checkbox checked>`)

Destructive reserved strictly for:
1. Overdue bill and overdue chore alert badges/indicators
2. Skipped payment indicator tags
3. Destructive confirmation dialog action buttons ("Delete bill", "Delete chore", "Delete errand", "Delete recipe", "Delete household")
4. Household departure delete confirmation step
