## Phase Goal

ROADMAP goal (verbatim): "Ensure reliable Web Push notifications on real HTTPS mobile devices, configure Cloudflare edge performance/security, and lock in quality gates."

This plan implements operator push verification tooling (`PUSH-02`): adding the `hestia-admin test-push` CLI command in `apps/service/src/cli.ts` (with root `package.json` wrapper) to load user push subscriptions and trigger instantaneous notifications; verifying all CLI behaviors and error paths with comprehensive Vitest tests; and authoring the standalone mobile PWA verification runbook in `docs/deployment.md` for iOS Safari 16.4+ and Android Chrome.

<threat_model>
### Security Threat Model (ASVS L1)
- **T-11-05** (ASVS 4.1.1 / PUSH-02): Privilege escalation or arbitrary push notification dispatch by unauthorized local callers.
  - Threat: An unprivileged process or unauthorized user attempts to trigger notification spam to arbitrary email addresses using the CLI.
  - Mitigation: `hestia-admin test-push` requires server host execution permissions (e.g. `docker compose exec hestia-service` or root shell access). The command queries `public.profile` by email; if no matching profile exists, it refuses dispatch and exits with code 1. Push payload is constrained to a fixed administrative template (`{ title, body, url: '/' }`).
  - Test: `apps/service/src/cli.test.ts` validates that non-existent users return error code 1 without dispatching push calls.
- **T-11-06** (ASVS 9.1.1 / PUSH-02): Stale push subscriptions causing delivery waste or leaking notifications to reassigned endpoints.
  - Threat: Devices that uninstalled the PWA or revoked permission leave orphaned subscriptions in `public.push_subscription`, causing repeated failed dispatches.
  - Mitigation: When `PushTransport.send` returns `{ kind: 'gone' }` (HTTP 404/410), the CLI immediately issues a service-role `delete from public.push_subscription where id = $1` to purge the expired token.
  - Test: `apps/service/src/cli.test.ts` verifies that `deleteSubscription` is called for any subscription returning `gone`.
</threat_model>

     export async function runCli(
       args: readonly string[],
       admin: Pick<GoTrueAdmin, 'recoveryLink'>,
       origin: string,
       io: CliIo,
       pushOps?: PushOps,
     ): Promise<number> {
       const [command, ...rest] = args;
       if (command === 'reset-password') {
         const [email, ...extra] = rest;
         if (email === undefined || extra.length > 0) {
           io.err(RESET_USAGE);
           return 2;
         }
         if (!z.email().safeParse(email).success) {
           io.err(`Not an email address: ${email}`);
           return 2;
         }
         try {
           const link = await admin.recoveryLink(email, `${origin}${SET_PASSWORD_PATH}`);
           io.out(link);
           io.err('One-time link; it expires in an hour. Hand it over in person.');
           return 0;
         } catch (error) {
           if (error instanceof GoTrueError && error.status === 404) {
             io.err(`No user has the email ${email}.`);
           } else if (error instanceof GoTrueError) {
             io.err(`GoTrue refused: ${String(error.status)} ${error.message}`);
           } else {
             io.err(
               `Could not create the link: ${error instanceof Error ? error.message : String(error)}`,
             );
           }
           return 1;
         }
       }

       if (command === 'test-push') {
         if (!pushOps) {
           io.err('Push operations are not configured.');
           return 1;
         }
         let email: string | undefined;
         let title = 'Test Push Notification';
         let body = 'This is a test notification from Hestia.';

         for (let i = 0; i < rest.length; i++) {
           const arg = rest[i];
           if (arg === '--email' && i + 1 < rest.length) {
             email = rest[++i];
           } else if (arg === '--title' && i + 1 < rest.length) {
             title = rest[++i];
           } else if (arg === '--body' && i + 1 < rest.length) {
             body = rest[++i];
           } else {
             io.err(PUSH_USAGE);
             return 2;
           }
         }

         if (!email) {
           io.err(PUSH_USAGE);
           return 2;
         }
         if (!z.string().email().safeParse(email).success) {
           io.err(`Not an email address: ${email}`);
           return 2;
         }

         const user = await pushOps.lookupUser(email);
         if (!user) {
           io.err(`No user has the email ${email}.`);
           return 1;
         }

         const subscriptions = await pushOps.listSubscriptions(user.id);
         if (subscriptions.length === 0) {
           io.err(`User ${email} has no active push subscriptions.`);
           return 1;
         }

         const payload = JSON.stringify({ title, body, url: '/' });
         let accepted = 0;
         let gone = 0;
         let failed = 0;

         for (const sub of subscriptions) {
           const outcome = await pushOps.transport.send(sub, payload);
           if (outcome.kind === 'accepted') {
             accepted++;
           } else if (outcome.kind === 'gone') {
             gone++;
             await pushOps.deleteSubscription(sub.id);
           } else {
             failed++;
           }
         }

         io.out(
           `Dispatched test push to ${subscriptions.length} device(s) for ${email}: ${accepted} accepted, ${gone} gone, ${failed} failed.`,
         );
         return 0;
       }

       io.err(GENERAL_USAGE);
       return 2;
     }
