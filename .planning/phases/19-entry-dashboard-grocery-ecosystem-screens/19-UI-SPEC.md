## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gaps, chip checkmark gap, badge padding |
| sm | 8px | Compact element gaps, button icon spacing, chip strip horizontal gap |
| md | 16px | Default element spacing, card padding, dialog padding, list row horizontal padding |
| lg | 24px | Section padding, modal bottom sheet horizontal padding, auth card padding |
| xl | 32px | Layout gaps, grid spacing between dashboard cards, scanner reticle corner offset |
| 2xl | 48px | Major section breaks, FAB clearance margin, empty state illustration offset |
| 3xl | 64px | Page-level spacing, Top App Bar container height (64px) |

Exceptions:
- `48px`: Accessible touch target minimum for icon buttons (`<md-icon-button>`), list row checkboxes, and delete actions.
- `56px`: Standard MD3 text field container height (`<md-outlined-text-field>`).
- `72px`: Deal product photo square thumbnail (`72px × 72px`) for compact deal card layout.
- `80px`: Shell navigation container dimension (`min-h-[80px]` NavigationBar / `w-[80px]` NavigationRail).

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Label | 12px | 600 | 1.5 |
| Body | 14px | 400 | 1.5 |
| Heading | 20px | 600 | 1.2 |
| Display | 28px | 600 | 1.2 |

Typography rules:
- Exactly 4 font sizes declared: 12px (Label / Caption / status badge text / helper text), 14px (Body text / descriptions / list rows / input values), 20px (Heading / Top App Bar single `<h1>` / card section `<h2>` / dialog title), 28px (Display / Auth hero titles).
- Exactly 2 font weights declared: 400 (Regular — body copy, descriptions, input text, inactive chip labels), 600 (Semi-bold/Medium — headings, display titles, button labels, active chip labels, card headers).
- Line heights: Body roles use 1.5 (21px for 14px body, 18px for 12px label); Heading and Display roles use 1.2 (24px for 20px heading, 34px for 28px display).

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FFF8F6` (light) / `#1A110E` (dark) | MD3 Surface canvas background, page main canvas (`bg-surface`), full-screen scanner dialog background |
| Secondary (30%) | `#FCEAE4` (light) / `#271E1A` (dark) | MD3 Surface Container (`surfaceContainer` / `surfaceContainerLow` `#FFF1EC` / `#231A16`): This Week cards, ModalBottomSheet surface, store group subheaders, dialog interiors, auth cards, navigation chrome |
| Accent (10%) | `#8E4C32` (light) / `#FFB599` (dark) | MD3 Primary (paired with `secondaryContainer` `#FFDBCE` / `#5D4035`): active indicators, selected chips, focus rings, primary action buttons |
| Destructive | `#BA1A1A` (light) / `#FFB4AB` (dark) | MD3 Error (paired with `errorContainer` `#FFDAD6` / `#93000A`): destructive confirmation dialogs, overdue alerts, expired pantry items |

Accent reserved strictly for:
1. Primary CTA button container backgrounds (`<md-filled-button>` / `<Button variant="primary">`)
2. Floating Action Buttons (`<md-fab>`) for creating shopping lists and adding items
3. Selected filter chips container (`<md-filter-chip selected>`) and active Segmented Button item (`Add to list | Mark bought`)
4. Scanner reticle pulsing laser scan line
5. Focus ring highlight outline (`--md-focus-ring-color`)
6. Checkbox checked fill on active grocery items (`<md-checkbox checked>`)

Destructive reserved strictly for:
1. Overdue alerts and indicators on Dashboard cards
2. Expired pantry item status badges
3. Destructive confirmation dialog action buttons ("Delete list", "Delete item")

## Visual Hierarchy & Focal Points

Each screen declares one primary visual anchor to guide user attention:

| Screen | Primary Visual Anchor | Supporting Elements |
|--------|-----------------------|---------------------|
| `DashboardScreen` (Populated) | Urgent overdue alert rows at top of `This Week` cards (`error` container + icon) | Card header title with pillar icon, max 3 items, "+N more in [Pillar]" text button |

| `ListDetailScreen` | Persistent top quick-add input field ("Add an item...") | Grouped store subheaders with collapse toggle, floating `<md-fab>`, collapsible `Bought (N)` section |
| `PantryScreen` | Top horizontal storage location filter chip strip (`All`, `Fridge`, `Freezer`, `Pantry`) | MD3 Search Bar, borderless item list with quantity and expiry indicator pills |
| `BarcodeScannerDialog` | Centered targeting reticle with terracotta pulsing scan line in dark HUD | Top Bar (`arrow_back` Close, `flashlight_on`), bottom container with `Add to list \| Mark bought` Segmented Button |
| `DealSearchScreen` | Top MD3 Search Bar with active search input | Filter chip row (`Favorites \| All stores`, `Category`, `Discount`), compact `DealFreshness` banner |
| `FlyersScreen` | Elevated store catalog cards with merchant logo and cover thumbnail | Store title, valid date range, circular item count badge |
| Auth & Onboarding screens | Centered tonal Surface Container card (`max-w-[440px]`) with display headline | Outlined text fields with floating labels, filled primary CTA button, secondary options below |

All icon-only buttons include explicit accessible text (`aria-label`) for screen readers and tooltips.

## UI Considerations

Applicable state considerations resolved: 14 covered, 0 backstop, 0 unresolved

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| empty | `DashboardScreen` (`This Week`) | ✅ covered | When all shipped pillars have zero active items, renders `DashboardFirstRun` hero card with quick-start action pills ("Create a shopping list", "Add upcoming bill", "Plan first meal"). References empty state copy in copywriting contract. |
| empty | `ListDetailScreen` active list | ✅ covered | When a shopping list has zero outstanding items, renders centered empty state with "Nothing on this list yet" copy and "Add grocery item" CTA. |
| empty | `ListDetailScreen` all bought | ✅ covered | When all items on a list are checked, renders "Everything on this list is bought" with prompt to "Add bought to pantry". |
| empty | `PantryScreen` inventory | ✅ covered | When pantry inventory is empty, renders centered empty state with "Nothing in the pantry yet" copy and "Add pantry item" CTA. |
| empty | `DealSearchScreen` query results | ✅ covered | When search keywords or filter chips match zero circular deals, renders "No matching deals found" with "Clear deal filters" action. |
| loading | `DashboardCard` pillar rows | ✅ covered | While pillar queries are pending, renders 3 tonal skeleton rows per card (`SkeletonRows`, `surfaceContainerHighest`) with accessible "Loading [pillar]" status announcements to prevent layout shift. |
| loading | `FlyersScreen` store grid | ✅ covered | While store catalogs are loading, renders elevated 2–4 column skeleton card grid matching target card geometry. |
| error | `DashboardCard` pillar query | ✅ covered | Card-scoped `ErrorBoundary` isolates failure to individual pillar; displays inline `ErrorState` with "Couldn't load [pillar] items" and "Retry loading" button without crashing adjacent cards. |
| error | `BarcodeScannerDialog` camera stream | ✅ covered | When camera access is denied or unavailable, displays camera error notice and immediate "Enter barcode manually" button navigating to numeric keypad view. |
| zero-one-many | `DealCard` "+ Add" action flow | ✅ covered | Tapping "+ Add" on a deal evaluates active list count: if exactly 1 active list exists, commits item immediately and shows persistent Undo Snackbar; if multiple active lists exist, opens `AddToListSheet` picker; if 0 active lists, prompts to create list. |
| zero-one-many | `Bought (N)` collapsible section | ✅ covered | Displays count in subheader pill: hidden when 0 items bought; expandable accordion when >=1 items bought, preserving collapse/expand toggle state in session storage. |
| overflow | `DashboardCard` active items limit | ✅ covered | Urgency-first ranking displays top 3 items (overdue first, then today, then this week); remaining items (>3) roll into a dedicated card footer text button: "+N more in [Pillar]" linking directly to that pillar's route. |
| overflow | `StoreGroupHeader` subtotal & unpriced | ✅ covered | Displays store name, item count, and subtotal; items without pricing data display "+N unpriced" indicator with screen-reader explanation without breaking horizontal alignment. |
| long-text | `ShoppingListRow` & `DealCard` item titles | ✅ covered | Item names and titles truncate with ellipsis (`truncate` / `line-clamp-2`), preventing layout breaks, button displacement, or price alignment overlap. |
