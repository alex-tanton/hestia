ROADMAP goal (verbatim): "Rebrand the application from Hearth to Hestia across the monorepo, UI, manifest, CLI, and configuration."

This plan delivers success criteria 1 ("PWA UI titles, shell header, onboarding copy, and home screen install banners display Hestia"), 2 ("Web App Manifest generates with `name: "Hestia"` and `short_name: "Hestia"`") and 3 ("Administrative CLI command is `hestia-admin`"), plus the browser-key rename of D-08: three reviewable commits.

<objective>
Make the user-visible product name Hestia in the PWA and its manifest, with a build-time check that fails if the built manifest or title regress; rename the owner CLI as a clean break; rename the two browser-persisted identifiers with no data migration.

Purpose: BRAND-01, BRAND-02 and BRAND-03; D-07, D-08 and D-10.

Output: a `feat(web)` commit with `check-build.mjs` check 3, a `refactor(service)` CLI commit, a `refactor(web)` keys commit; green web and service tests, a web build whose manifest says Hestia, and a CLI wrapper that runs under its new name.
</objective>
