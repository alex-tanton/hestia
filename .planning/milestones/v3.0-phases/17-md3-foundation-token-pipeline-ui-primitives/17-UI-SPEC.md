## Spacing Scale

Declared values (multiples of 4 only):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Inline icon-to-label gaps, compact vertical captions |
| sm | 8px | Compact element spacing, button group gaps, alert row gaps |
| md | 16px | Default card/sheet horizontal padding, element spacing, snackbar horizontal inset |
| lg | 24px | Dialog padding (`ConfirmDialog`), section vertical padding |
| xl | 32px | Major form/group layout gaps |
| 2xl | 48px | Minimum list-row height (`ListRow`), major block separation |
| 3xl | 64px | Page-level spacing and wide-viewport outer breathing room |

Exceptions:
- `44px` minimum interactive touch target (`min-h-11 min-w-11`): Required by WCAG 2.5.5 and existing Hestia button/checkbox/menu-item contracts (`Button`, `Checkbox`, `ListRow`, `SegmentedControl`, `Tabs`, `OverflowMenu`, `ModalBottomSheet` close button, `Snackbar` dismiss button).
- `56px` outlined form field height (`min-h-14`): Required to align light-DOM `DateField` / `TimeField` and `(pointer: coarse)` native `<select>` cleanly with `<md-outlined-text-field>` / `<md-outlined-select>` (`56dp` MD3 outlined field height).

## Typography

Phase 17 locks **4 contract font sizes** and **2 font weights** over the native system UI sans-serif font stack (`--md-ref-typeface-plain` / `--md-ref-typeface-brand`, `D-04`):

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Label | 14px (`0.875rem`) | 600 (semibold; 400 regular for supporting/error text) | 1.4 |
| Body | 16px (`1rem`) | 400 (regular) | 1.5 |
| Heading | 20px (`1.25rem`) | 600 (semibold) | 1.2 |
| Display | 28px (`1.75rem`) | 600 (semibold) | 1.2 |

CSS mapping rules:
- `tokens.css` defines `--md-ref-typeface-brand` and `--md-ref-typeface-plain` as `ui-sans-serif, system-ui, -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, 'Helvetica Neue', Arial, sans-serif` (zero external font requests, zero WOFF2 precache weight).
- `--md-sys-typescale-*` tokens consumed by `@material/web` internals bind strictly to those 4 sizes (`14px`, `16px`, `20px`, `28px`) and 2 weights (`400`, `600`) so control typography matches Hestia light-DOM typography without introducing extra visual noise.
- Native form controls (`TextField`, `TextAreaField`, `Select`, `DateField`, `TimeField`) render input text at `16px` (`Body`) so iOS Safari never auto-zooms on focus.

### Theme Activation & Legacy Tailwind Coexistence (`D-02`, `D-03`)

- **Cascade order in `tokens.css` (zero inline `<script>` in `index.html`):**
  1. `:root` sets `color-scheme: light dark;` + light `--md-sys-*` tokens and static shape/elevation/typescale tokens.
  2. `@media (prefers-color-scheme: dark) { :root:not([data-theme='light']) { ... } }` applies dark tokens automatically from OS preference unless explicitly overridden to light.
  3. `:root[data-theme='light']` (`color-scheme: light;`) and `:root[data-theme='dark']` (`color-scheme: dark;`) allow deterministic light/dark overrides (for Playwright audits and future theme selectors).
- **Browser & PWA chrome (`D-03`):** `apps/web/index.html` removes `#475569` and declares `<meta name="color-scheme" content="light dark" />`, `<meta name="theme-color" media="(prefers-color-scheme: light)" content="#fff8f6" />`, and `<meta name="theme-color" media="(prefers-color-scheme: dark)" content="#1a110e" />`; `vite.config.ts` manifest sets `theme_color: '#fff8f6'` and `background_color: '#fff8f6'`; `scripts/generate-icons.mjs` replaces `#475569` icon background with Warm Terracotta (`#B4532A`).
- **Tailwind v4 bridge (`apps/web/src/index.css`):** Remove all five `[data-section='*']` multi-hue color ramps and remap `--bg-*`, `--text-*`, `--border*`, `--section*`, `--danger*`, `--warning*`, `--success*`, `--info*`, and `--neutral-badge*` directly to `--md-sys-color-*` until Phase 21 removes Tailwind (`FND-05`).

## Copywriting Contract

Phase 17 primitives enforce specific, actionable user copy and preserve Hestia's existing verified UX messaging contracts:

| Element | Copy / Pattern |
|---------|----------------|
| Primary CTA | Specific `verb + noun` required on every primary button (examples in primitives/tests: `"Copy invite link"`, `"Add item"`, `"Create list"`, `"Try again"`). Generic single-word or ambiguous CTAs (`"Submit"`, `"OK"`, `"Save"`, `"Click Here"`) are prohibited. |
| Empty state heading | Context-specific empty heading naming the missing collection (e.g., `"No chores scheduled yet"`, `"No active shopping lists"` — generic `"No data found"`, `"No results"`, or `"Nothing here"` prohibited). |
| Empty state body | One concise line stating what appears here plus a primary `verb + noun` action (e.g., `"Add a household chore or recurring task to see upcoming reminders here."` paired with `"Add chore"`). |
| Error state | Explicit problem + recovery path: `FormMessage` (`role="alert"`) and field errors pair `<Icon name="error" />` with corrective instructions (e.g., `"That password is too common. Choose another."`); `CopyButton` clipboard failure triggers persistent error `Snackbar`: `"Could not copy. Select the text and copy it by hand."`; failed saves show persistent error `Snackbar`: `"Couldn't save changes. Check your connection and try again."`; offline-unavailable controls show inline `disabledReason`: `"Needs a connection."`. |
| Destructive confirmation | `ConfirmDialog` (`<md-dialog type="alert">`, outside backdrop dismissal blocked): pairs a question title naming the target with a consequence description stating exact scope, a specific `verb + noun` `confirmLabel` (`variant="destructive"`), and a safe dismissal button (recommended `"Keep item"` / `"Keep household"` / `"Go back"`, preserving `cancelLabel` prop compatibility for existing callers). Examples: `"Delete Oak Street?"` -> `"This deletes 4 lists, 23 recipes, and 6 chores permanently."` + `"Delete household"`; `"Delete This Week?"` -> `"Its 15 items are removed permanently."` + `"Delete list"`. |
| Snackbar (`Toast.tsx`) & Undo feedback | Single active slot backed by FIFO queue (`D-11`): `success`/`info` without `action` auto-dismiss in `4000ms` (e.g., `"Added to Grocery List."`, `"3 changes synced."`); `error` and any toast with `action` (e.g., `"Take out trash done. Sam is next."` + `"Undo"`) persist (`Number.POSITIVE_INFINITY`) until the user invokes `"Undo"` or clicks the `aria-label="Dismiss"` Close button. |

## Primitive Interaction & Wrapper Rules (`FND-02`, `FND-03`, `FND-04`)

### 1. `@material/web` React 19 Interop (`components/md/` -> `components/ui/`)
- **Strict Import Fence (`eslint.config.js`):** Add `@typescript-eslint/no-restricted-imports` + dynamic `ImportExpression` checks banning `@material/web`, `@material/web/*`, `lit`, `lit/*`, and `@lit/*` outside `apps/web/src/components/md/`. Only explicit subpath imports are allowed inside `components/md/` (no `all.js`, no `labs/*`).
- **`exactOptionalPropertyTypes` Normalization (`components/md/props.ts`):** Strip `undefined` keys with a typed `omitUndefined` helper (zero `as` casts) before forwarding props to `@lit/react` `createComponent` wrappers.
- **Button Interop (`Button.tsx`):** Default `type = 'button'` (overriding `mixinFormSubmitter` `'submit'` default). Forward `softDisabled={isUnavailable}`, `aria-disabled={isUnavailable || undefined}`, `aria-busy={isLoading || undefined}`, and `aria-describedby` to host, AND short-circuit React synthetic `onClick`: `if (isUnavailable) { event.preventDefault(); event.stopPropagation(); return; }`. Render `<md-circular-progress indeterminate>` inside loading buttons.
- **Select Positioning (`Select.tsx`):** Preserve `(pointer: coarse)` `useSyncExternalStore` native `<select>` styled as an outlined `56px` field on touch devices; fine-pointer renders `<MdOutlinedSelect menuPositioning="fixed">` (NOT `positioning="fixed"`, which is ignored by `md-select`). Standalone `<MdMenu>` uses `positioning="fixed"`.
- **Switch & Checkbox Labels (`Switch.tsx`, `Checkbox.tsx`):** Bind `<MdSwitch selected={checked}>` (NOT `checked`) and map both `onInput` / `onChange` reading `event.currentTarget.selected`. Preserve `Checkbox` `variant="in-list"` full-row `min-h-11 px-4 py-3` `<label>` tap target. Enforce explicit labels via `'jsx-a11y/control-has-associated-label': ['error', ...]` and `'jsx-a11y/label-has-associated-control': ['error', ...]` in `eslint.config.js` (do NOT alias `Checkbox` or `Switch` to `'input'` in `settings['jsx-a11y'].components`).
- **`useFieldErrors` Focus (`TextField`, `TextAreaField`, `Select`, `DateField`, `TimeField`):** Mirror `aria-invalid={isInvalid || undefined}` on the host/control element matched by `formRef.current?.querySelector('[aria-invalid="true"]')?.focus()` and ensure `.focus()` reaches the editable element. Never add redundant `role="button"`/`role="checkbox"`/`role="textbox"` attributes onto `<md-*>` custom element hosts.
- **Dialog Sync (`ConfirmDialog.tsx`):** Sync `<md-dialog type="alert">` open state via `closed` and `cancel` events; suppress backdrop outside clicks (`event.preventDefault()` on non-Escape `cancel`), focus safe dismiss button on open, and keep `ConfirmDialog` backdrop locked.

### 2. Curated Material Symbols Inline SVG Contract (`Icon.tsx`, `D-05`–`D-08`)
- Single static registry in `apps/web/src/components/ui/Icon.tsx` (`icon-paths.ts`) sourced from `@material-symbols/svg-400@0.48.3/rounded/*.svg` (`~54` outline icons + `-fill.svg` variants when `filled={true}` for active nav/favorites/toggles; `LoaderCircle` replaced by `<md-circular-progress indeterminate>`).
- Render purely as `<svg viewBox="0 -960 960 960" aria-hidden="true" width={size} height={size} fill="currentColor"><path d={path} /></svg>` (zero `dangerouslySetInnerHTML`, zero WOFF2 font precache weight, zero screen-reader ligature text leakage, Caddy `'self'` CSP compliant, verified `<= 200 KB` gzipped shell budget in `check-build.mjs`).

### 3. Light-DOM / Native-`<dialog>` Gap Primitives (`FND-04`)
- **`ModalBottomSheet` & `Sheet.tsx`:** Native `<dialog>` opened/closed via `showModal()` / `close()` in `useEffect` (no redundant `role="dialog"`/`aria-modal`), `closedby="any"` + `pointerdown`/`pointerup` outside-`getBoundingClientRect()` fallback when `!('closedBy' in HTMLDialogElement.prototype)`, `dialog[open] { display: flex; flex-direction: column; }`, `dialog:modal { overscroll-behavior: contain; }`, `dialog::backdrop { overflow: hidden; overscroll-behavior: contain; }`, `@starting-style` + `transition-behavior: allow-discrete` inside `@media (prefers-reduced-motion: no-preference)`, `dialog.returnValue = ''` reset on close, `previousFocusRef` restoration, explicit `aria-label="Close"` header button, and `SheetProps` preserved in `Sheet.tsx`.
