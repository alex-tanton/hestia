- Keep (D-08): a parenthetical or sentence that also carries the rule keeps the rule and loses only the attribution. A colon-led clause or a quoted rule after the reference becomes plain words (for example a numbered-rule parenthetical whose text is "equal weighting, half-up rounding" keeps just `(equal weighting, half-up rounding)`). A sentence whose subject is a retired document states the rule itself (a comment saying a document allows non-null assertions in tests only becomes `Non-null assertions are allowed in tests only.`). The seed-fixture source is written `the seed data` in lower case, meaning `supabase/seed`. Never replace a citation with a pointer into `docs/`. A comment that is the only content of a block keeps a short why-comment, because an empty block fails `no-empty`.
- Not citations (left alone, counted in the ledger): product-phase mentions such as "Phase 3 owns the threshold" on lines that match nothing in the vocabulary (research A10).
- Comment batches never touch string literals, JSX text, template literals or code. The test titles (D-19) are 05-10's separate commit; HTML body text (D-20) is 05-10's.
- Directive guard (Pitfall 7): no removed line may contain `eslint-disable`, `@ts-`, `v8 ignore`, `c8 ignore`, `istanbul`, `prettier-ignore`, `<reference`, a shebang or a Dockerfile `# syntax=` line.
