## Phase Goal

ROADMAP goal (verbatim): "Establish secure ingress for `hestia.aberrance.app` via Cloudflare Tunnel, eliminating Tailscale Funnel and port forwarding."

Success criterion 5 is "Base origin across all services points to `https://hestia.aberrance.app`". 09-01 put the origin in `.env.example` and pinned the GoTrue derivations; the service reads `HESTIA_ORIGIN` with no code default (D-08), and the web app has no origin setting at all. What is left is the test suites, which still build and assert links on made-up hosts under the retired private network's domain. This plan moves them to the real origin (planner decision 3), so the guard in 09-05 can cover `apps/` and `packages/`.

<objective>
Replace every made-up origin host in the unit and component tests (and the one `env.ts` comment) with `https://hestia.aberrance.app`, leaving test logic unchanged, and prove every touched suite still passes.

Purpose: NET-05's acceptance is that generated links use `https://hestia.aberrance.app`; the tests that prove link building, display and scrubbing should assert exactly that origin.

Output: two commits of literal-only changes.
</objective>
