Never run `git checkout {rev}`, `git switch`, `git reset`, `git stash` or `git clean` in the primary checkout. A `.planning/` script that must be executable gets `chmod +x` on disk and `git update-index --chmod=+x` before its commit, and `git ls-tree HEAD -- {path}` shows `100755` after it.

Code branches live only in sibling worktrees, created with `git worktree add {dir} -b {branch} {base}` and then `pnpm --dir {dir} install --frozen-lockfile` (that installs the Husky hooks): W1 `/home/user/hearth-gate-scripts` (`ci/gate-scripts`, PR 1), W2 `/home/user/hearth-enforce-gates` (`ci/enforce-gates`, PR 2), W3 `/home/user/hearth-gate-canaries` (`ci/gate-canaries`, the throwaway canary, never merged), W4 `/home/user/hearth-ci-lock-in` (`docs/ci-lock-in`, PR 3).
