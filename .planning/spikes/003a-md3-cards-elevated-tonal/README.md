# Spike 003a: MD3 Cards Elevated Tonal

## What This Validates
Given the 4 dashboard pillars (Bills, Shopping, Meals, Chores), when styled as MD3 Elevated / Surface Container cards with soft tonal badges and structured typography, then the dashboard delivers optimal readability and visual hierarchy.

## Research
MD3 Elevated Cards use `surface-container-low` with subtle elevation level 1 shadow. Nested list items sit on `surface-container-lowest` to create distinct physical depth without harsh lines.

## How to Run
Open `.planning/spikes/003-comparison.html` to view Option A vs Option B side-by-side.

## Results
- **Verdict:** VALIDATED (Option A in comparison)
- **Visual characteristics:** Warm, physical depth, clear separation between pillar cards and the canvas.
