<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client -> Fastify API | Untrusted barcode input and authentication tokens cross from browser to service |
| Fastify Service -> Open Food Facts | Outbound HTTPS requests to external public API |
| Fastify Service -> Postgres | Cache reads/writes and list item mutations cross database boundary |
| Browser Ingress -> Client | Caddy HTTP security headers dictate browser device permissions (camera, WASM) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-14-01 | Elevation of Privilege | GET /api/barcodes/:barcode | high | mitigate | Authenticate request with ctx.authenticate(request); reject missing or invalid JWTs with 401 Problem Details. |
| T-14-02 | Denial of Service | Open Food Facts v3 proxy | high | mitigate | Enforce 5,000ms AbortController timeout on outbound fetch, cache resolved products indefinitely in Postgres barcode_products table to eliminate duplicate upstream queries, and format compliant RFC User-Agent header to avoid rate limits. |
| T-14-03 | Tampering / Injection | Barcode input & URL formation | medium | mitigate | Validate barcode parameters with barcodeSchema (alphanumeric, 3 to 64 characters), URL-encode parameter via encodeURIComponent, and hardcode upstream host to https://world.openfoodfacts.org/api/v3/product/... without user redirection. |
| T-14-SC | Tampering | npm dependencies | high | mitigate | Zero external npm packages introduced in service tier; all proxy logic uses native fetch, built-in Node.js AbortController, Kysely query builder, and existing workspace packages. |
</threat_model>
