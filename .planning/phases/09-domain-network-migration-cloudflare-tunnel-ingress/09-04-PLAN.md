## Phase Goal

ROADMAP goal (verbatim): "Establish secure ingress for `hestia.aberrance.app` via Cloudflare Tunnel, eliminating Tailscale Funnel and port forwarding."

Success criterion 1 asks for the retired ingress's dependencies, host-loopback proxy requirements and documentation to be removed. 09-01 to 09-03 removed them from code and config. This plan removes them from the docs (D-10), and writes the Cloudflare Tunnel runbook (D-11) and the owner checklist that the merge depends on. Merging to `main` deploys, so the owner's `.env` must hold the token and the new origin before merge.
