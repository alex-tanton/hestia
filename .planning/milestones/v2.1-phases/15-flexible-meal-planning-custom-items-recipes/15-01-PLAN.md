## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client -> Fastify API | Untrusted meal plan item input and authentication tokens cross from browser to service |
| Fastify Service -> Postgres Database | Database queries, inserts, and check constraints enforce storage-level integrity |
| Meal Plan -> Shopping List | Cross-feature translation of planned meal entries into shopping list items |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-15-01 | Input Validation / Denial of Service | POST /api/households/:id/meal-plan (customTitle) | high | mitigate | Shared Zod schemas trim and bound customTitle (.min(1).max(200)), rejecting empty, whitespace-only, or excessively long string payloads before reaching database. |
| T-15-02 | Tampering | meal_plan_entry table | high | mitigate | Database check constraint meal_plan_entry_recipe_or_custom strictly enforces mutually exclusive recipe XOR custom item states, rejecting corrupt rows. |
| T-15-03 | Elevation of Privilege | Meal plan & list export endpoints | high | mitigate | All route handlers enforce user authentication via ctx.authenticate(request) and household isolation via ctx.inHousehold(user, id) or ctx.asUser(user). |
| T-15-SC | Tampering | npm dependencies | high | mitigate | Zero external npm dependencies introduced; uses existing workspace libraries and native Postgres 17 constraints. |
</threat_model>
