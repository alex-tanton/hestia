<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client URL / History -> TopBar Back Link | ScreenChrome backTo paths originate from internal application route strings. Untrusted input must not control the back navigation destination. |
| Screen Chrome Title -> DOM <h1> | Dynamic titles supplied by screens or database entities (recipes, chores) render inside the TopBar <h1>. Untrusted text must not execute arbitrary scripts. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-18-01 | Spoofing | TopBar back link (backTo) | medium | mitigate | Restrict backTo to relative application paths registered via useScreenChrome, never arbitrary external URLs. |
| T-18-02 | Tampering | TopBar screen title (<h1>) | high | mitigate | Render title exclusively via React text interpolation ({title}), never dangerouslySetInnerHTML. |
| T-18-SC | Tampering | npm packages | high | mitigate | Zero new dependencies introduced. All imports verified against pinned packages in package.json. |
</threat_model>
