| Boundary | Description |

| User Input → Shopping List Items | Untrusted text input in item names, notes, and list titles |
| Household State → Shopping Lists | List deletion and item mutation across household boundaries |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-19-05 | Tampering | ItemSheet.tsx / ShoppingListRow.tsx | medium | mitigate | Validate item names and quantities against Zod schemas (itemNameSchema); React 19 JSX escapes strings automatically to prevent XSS. |
| T-19-06 | Elevation of Privilege | ListsIndexScreen.tsx / ListDetailScreen.tsx | medium | mitigate | List IDs are validated server-side against the user's active household session; destructive list and item deletion requires explicit confirmation dialogs or persistent undo snackbars. |
| T-19-SC | Tampering | npm dependencies | high | mitigate | Zero new dependencies introduced. Native HTML dialog and @material/web custom elements used exclusively. |
</threat_model>
